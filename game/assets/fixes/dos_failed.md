# DoS Attack Didn't Start

The DoS form couldn't start its attack threads against the target.

## Check

- **Is the target valid?** Enter an IP address (for example `192.168.4.1`) that **NMap** reported as up.
- **Privileges.** Flooding uses raw packets, so restart the game **as Administrator** or with `sudo`.
- **Capture driver (Windows).** Install **Npcap** from [npcap.com](https://npcap.com).

Only aim the DoS at the lab's own devices.
