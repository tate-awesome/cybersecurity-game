# No Network Connection

The game couldn't work out your computer's IP address, so it doesn't know which network to scan. This usually means the computer isn't connected to any network.

## Fix

1. Connect to the lab network: join its Wi-Fi, or plug in its Ethernet cable. The **WiFi Switch** form can switch to the device's network for you.
2. Check that the connection has an address. Run `ipconfig` (Windows) or `ip addr` (Linux/macOS) and look for an IPv4 address such as `192.168.x.x`.
3. Try the scan again.

A VPN can also hide the real network. Turn it off while you're working in the lab.
