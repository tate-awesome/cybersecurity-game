# Network Not Found

No network in range matched the **Device Name** you entered.

## Check

- **The name.** Device Name matches any network whose name *contains* what you typed, ignoring capitals. Open the **View report** on the *Detected networks* toast to see every network that was in range, then pick the right name from there.
- **Range.** Move closer to the device, or check that it's powered on and broadcasting. A device that just turned on can take a few seconds to show up.
- **Hidden networks** don't show in a scan. Connect to one by hand once, then try again.
