# No Saved Connection

The device's network is in range, but your computer has never connected to it, so it has no saved password (*profile*) to connect with.

## Fix

1. Connect to the device's network **by hand once**, from the system Wi-Fi menu, and enter its password.
2. Switch back to your usual network if you like.
3. Click **Connect to device** again. The game reuses the saved profile from then on.
